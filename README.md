# ZIP Image Viewer

A simple web-based image viewer for ZIP files. Drag and drop a ZIP file to view images inside.

## Features

- 🎯 Drag & Drop ZIP files
- 🖼️ Supports JPG, PNG, GIF, BMP, WebP formats
- ⌨️ Navigate with arrow keys (← →)
- 🌐 Works in any modern browser
- 📦 No installation required

## Usage

1. Open `index-web.html` in your browser
2. Drag and drop a ZIP file containing images
3. Use arrow keys to navigate between images
